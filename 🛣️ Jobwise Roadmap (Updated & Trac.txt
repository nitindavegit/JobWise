🛣️ Jobwise Roadmap (Updated & Tracked)
🚀 Week 1: Project Setup & Models (✅ Completed)
 Set up FastAPI backend.

 Set up PostgreSQL database.

 Install & configure SQLAlchemy, Alembic.

 Create Base Models:

Users

Candidates (with resume_text)

Jobs

 Create matching Pydantic Schemas.

📚 Week 2: Core APIs – User, Resume, Jobs (🛠️ In Progress)
 Build /signup API:

Accept name, email, password.

Hash password and store in users table.

 Build /upload_resume API:

Accept resume text.

Link resume to the user in candidates table.

 Insert demo job entries into jobs table.

At least 5-10 jobs.

 (Optional) Build /login API:

Authenticate user.

Return JWT token for session.

🔥 Week 3: Basic Matching Logic
 Parse resume text: extract important keywords.

 Simple matching:

Compare resume keywords with job descriptions or skills.

Find top 3-5 matching jobs.

 Build /recommend_jobs API:

Input: user id / JWT token.

Output: list of matching jobs with score.

🤖 Week 4: AI Enhancement (Optional)
 Use better techniques for matching:

TF-IDF

Embeddings (optional)

Cosine similarity

 Improve job ranking based on:

Skills

Experience

Education

🎨 Week 5: Polishing & Frontend Ready (Optional)
 Clean API responses.

 Add documentation with FastAPI Swagger UI.

 Prepare Frontend Plan (basic Web UI or mobile app later).
